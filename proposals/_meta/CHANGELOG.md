## RAR · Reference-Anchored Reverse — Phase B nl2mql 重构 (2026-06) — Active

**Focus**: 从第一性原理重构 **Phase B 的 nl2mql 构造**,根治逆向管线「operator-first 种子 → 不自然 NLQ / gold 自证」的病根。诊断:旧 QPS 先从覆盖配额采样**算子骨架**(`primary_pattern`),MS 编译、NLP 逆向转写——把**算子当因、问题当果**,因果倒置,导致 NLQ 沦为伪代码、gold 仅靠「自证」(gold↔NLQ 自洽,抓不到 gold 自身 bug)。**五项修订:(1) 种子方向** 废止算子采样;QPS 重定位为**意图枚举器**,种子是「Gate-QB query-bearing 异构 × archetype × 域」逼出的真实信息需求,算子/难度/cfs 全为 gold 锁死后**派生**的果。**(2) 拱心石 archetype 目录**(§04-2-4):按 DAR 机制索引的封闭目录,每条目挂 {问题形状, **参照实现 R 模板**, 落出难度};intent/gold判据/NLQ/覆盖全从此流出;只收「naive R 可审计」的操作。**(3) 参照锚定正确性(逆向骨架不变)**:gold 仍在 NLQ 之前锁死,但锁死判据从纯逆向自证改为 `NormExec(gold,D) ≡_rec R(D) ∧ 双路收敛`——R 是独立 Python 跨范式参照,抓得到 gold 系统性 bug;NLP 改从 **intent**(非锁死管线)派 NLQ,根治伪代码。**(4) cfs 坍缩 + 职责三分**:结构判别力本由 witness(P3/L2)承担,cfs 富指纹与之重复且误杀等价 idiom;**cfs 坍缩为 output-space 守卫**(`must_not_contain`=6 禁用 + shape 守卫,`must_contain` 仅 idiom-不变量、可空);正确性=R+双路+mutations、唯一性=RTV 结果级 ≡_rec + 意图歧义攻击、难度合法=dual-bridge **纯结果**(去 结构代理拐杖,判据「SQL/模板路线都够不到 ≡_rec gold」),三家零重叠。C6 放宽(`must_contain_at_root` 可空)。**(5) ③ 后门焊死 + 混合披露**:③ 类型漂移改「仅真实混合类型列才恢复,**永不合成**」,五机制无合成例外;`__variants` 明确为**混合披露**契约(声明 discriminator + 字段集 + presence,**不**承诺判别值→精确字段集的确定函数、不声明逐 doc 形状),Gate-SD 改判**集合级**——恰好让 06 probe-based solver 有意义(S 给线索、D 给真相)。**净效果**:naturalness/正确性/唯一性/native/legit 五性质同时拿满;比纯逆向更能保证正确(独立 R)、比正向真能保证正确、且更简单(删 cfs 富指纹、结构代理拐杖、③ 后门、NLQ 转写风险、算子配额)。**保留** Phase A 全套 DAR、逆向骨架(gold 先锁)、MUT/PV/NNC/RA、P1–P4、EX 双条件形式、test-only。落卷:01(§01-3 cfs/EX、§01-6 P1=gold≡R/P3、§01-7 锚注)、02(§02-2 cfs thin/`reference_oracle_ref`/Gate-SD 集合级/C6、§02-4 覆盖轴→seed_mechanism×question_archetype×domain)、03(§03-6 ③真信号/混合披露/Gate-SD)、04(§04-2 意图枚举+archetype+R、§04-3 MS gold-lock+thin cfs、§04-4 RTV 结果级/NLP 从 intent、§04-5 NNC 派生/dual-bridge 纯结果、Part II 伪代码)、GLOSSARY。跨卷锚 `financial/1001` 字节冻结(其富 cfs 为 pre-collapse 遗留,并入既有 PENDING DAR Phase A,执行验证时按 thin 重派生)。**协调项**:05 的 `structural_sql_solvable` 诊断、`schemas/query_plan.schema.json`→`intent.schema.json` 重命名、`agent_prompts/` 12 prompt 与 R 模板实现、06 probe-solver 对混合披露的消费——评审后实施。
